# Non-technical Summary — DR-001

The proposal is a small review screen so an operations person can make an explicit decision about an exceptional order and record why. The demo uses invented orders and does not move real money or fulfill anything.

After human acceptance, the change can be shown in staging only after the code, tests and review evidence line up. Production is intentionally not enabled; a real launch would need a separate decision about identity, storage, retention and operational ownership.
