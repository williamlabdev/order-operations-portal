# Governance Policy

- Request owner: `demo/operations`
- Technical decision approver: `demo/platform`
- Operating mode: `single_operator` for this low-risk synthetic demo.
- AI technical reviewer: separate agent run and actor identity; this is not a human approval.
- Staging approver: the Founder may self-approve staging only when the compensating-control evidence is PASS.
- Independent human code reviewer and separate release approver: required before production or higher-risk changes.
- Data classification: synthetic internal fixture.
- Production: protected/read-only and out of scope.
